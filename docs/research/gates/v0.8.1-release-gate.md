## Ruling: adoption stands in for the live-account gate

**Craig's call, 2026-10-03** (took the recommended default). Step 5's live gate against the real
Proton account is not run for 0.8.1. Installing the draft's bytes on Craig's machine, with a fleet
verify from a fresh session, stands in for it, as it did for 0.8.0.

Basis: between `v0.8.0` and `v0.8.1` there is no change at all to the helper's source or to the
installer (`git diff v0.8.0 v0.8.1 -- cmd internal go.mod go.sum install.ps1` is empty), so the
built `git-remote-proton.exe` differs from v0.8.0's only by the `-X main.version` string. The
module change is covered by the Pester suite: 187 tests on the merged tree (24 of them for #10),
green in CI under Pester 6.2.0 and locally under 5.7.1, with the #10 tests also run locally under
6.2.0.

Not taken: a formal live gate (a brief written against `brief-checklist.md`, writes confined to a
gate folder under `/my-files/GitRemotes`), which would re-exercise helper code identical to
v0.8.0's.
