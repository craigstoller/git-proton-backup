## Confinement (rules 2, 3, 7 and 8)

- **Writes go only under `/my-files/GitRemotes/v010-linux-*-<SUF>`.** That means the four repo
  roots above, plus the contract live root, all carrying this attempt's SUF.
  - The contract live root is the `GPB_CONTRACT_LIVE_ROOT` value step 2 sets, for one command only.
    It is named here and is part of this list (rule 8).

  never touches an earlier attempt's root or anyone else's node. A run BLOCKED at step 0 owns
  nothing and trashes nothing.
- **`/my-files/GitRemotes` itself:**

## Shells, the runner kit, timeouts and BLOCKED

**Two shells.** Each block below is labelled either `pwsh` (Windows PowerShell 7) or `bash` (the
WSL distro).

- **A `bash` block that starts with a script name** (`# script: <name>`) is a script. The runner
  saves it exactly as written to `C:\gpb010\wsl\<name>.sh` (probe prep says when) and runs it from
  pwsh with `. C:\gpb010\kit.ps1; Invoke-GateWsl <name>`. The launcher hands the script the current
  run's name as `$1`. Never inline a script as `wsl -- bash -c "<commands>"`: WSL's launcher
  expands `$vars` before bash ever sees them.
- **A `bash` block marked "Craig types"** belongs in Craig's own interactive WSL terminal.
- **Every pwsh block that uses a kit function starts by dot-sourcing the kit.** Separate
  PowerShell calls share no functions. The kit's variables are `$Root`, `$Run`, `$G` (the run's
  folder), `$Suf`, `$GR` (`/my-files/GitRemotes`), `$CONTRACT`, `$SMOKE`, `$XL`, `$XW`, `$CASE`
  and `$RootNames`. PowerShell variable names ignore case, so no block below assigns `$gr`, `$g`,
  `$run`, `$xl` or any other name that folds to one of these.

**The kit.** The runner saves this exactly as written to `C:\gpb010\kit.ps1`:

```powershell
# C:\gpb010\kit.ps1 - the Windows-side helpers of the v0.10.0 Linux probe and gate.
# Dot-source it at the start of every PowerShell call:  . C:\gpb010\kit.ps1
# Its only account calls are `filesystem list` and `filesystem info`, both read-only.
# Every name comparison is case-sensitive (-ceq, -clike, ordinal sets): Main and main differ.
[Console]::OutputEncoding = [Text.UTF8Encoding]::new()
$Root = 'C:\gpb010'
$lagWait = 60      # seconds Save-Snapshot waits before each re-take of a listing that shows trash lag
$lagRetakes = 2    # at most two re-takes: stage6-gate.md 5.4 saw lag at 21 s and none by 112 s

# The current run, named by C:\gpb010\run.txt (probe-a1, gate-a1, ...; Start-GateRun writes it).
# $G is the run's folder, $Suf its attempt (a1, a2, ...), which every remote root name carries.
$Run = $null; $G = $null; $Suf = $null; $errLog = Join-Path $Root 'cli-stderr.txt'
if (Test-Path -LiteralPath (Join-Path $Root 'run.txt')) {
    $Run = (Get-Content -LiteralPath (Join-Path $Root 'run.txt') -Raw).Trim()
    if ($Run -cnotmatch '^(probe|gate)-a[1-9][0-9]*$') { throw "kit: run.txt names '$Run', which is not a run name" }
    $G = Join-Path $Root $Run
    $Suf = $Run -creplace '^(probe|gate)-', ''
    $errLog = Join-Path $G 'log\cli-stderr.txt'
}
# This run's remote names (a gate run's; a probe run writes nothing remote).
$GR = '/my-files/GitRemotes'
$RootNames = @(foreach ($role in 'contract', 'smoke', 'xl', 'xw', 'case') { "v010-linux-$role-$Suf" })
$CONTRACT = "$GR/v010-linux-contract-$Suf"; $SMOKE = "$GR/v010-linux-smoke-$Suf"
$XL = "$GR/v010-linux-xl-$Suf"; $XW = "$GR/v010-linux-xw-$Suf"; $CASE = "$GR/v010-linux-case-$Suf"

function Assert-Run {
    if (-not $G -or -not (Test-Path -LiteralPath $G)) { throw 'BLOCKED: no current run (C:\gpb010\run.txt names none, or its folder is missing)' }
}

# Starts a run: creates C:\gpb010\<kind>-a<attempt> with log\, snap\ and refsets\, and names it
# in run.txt. A run folder that already exists is a stale attempt: BLOCKED, and nothing is written.
# Dot-source the kit again before the next command, so $G and the names follow the new run.
function Start-GateRun([string]$Kind, [int]$Attempt) {
    if ($Kind -cnotin 'probe', 'gate' -or $Attempt -lt 1) { throw 'Start-GateRun: the kind is probe or gate, and the attempt is 1 or more' }
    $name = "$Kind-a$Attempt"
    $dir = Join-Path $Root $name
    if (Test-Path -LiteralPath $dir) { throw "BLOCKED: $dir already exists (that run already started; a re-run takes the next attempt number, on Craig's word)" }
    New-Item -ItemType Directory -Path $dir, (Join-Path $dir 'log'), (Join-Path $dir 'snap'), (Join-Path $dir 'refsets') -ErrorAction Stop | Out-Null
    Set-Content -LiteralPath (Join-Path $Root 'run.txt') -Value $name -NoNewline
    "RUN STARTED: $name ($dir) at $(Get-Date -Format o). Dot-source the kit again before the next command."
}

# Runs C:\gpb010\wsl\<Name>.sh in the distro, with the run name as its $1. Its output (stderr
# merged) is shown and appended to <run>\log\<Name>.txt one line at a time as it arrives, and
# STARTED and EXIT lines go to <run>\log\runs.txt, so a run the harness kills keeps its partial
# output and shows a STARTED with no EXIT. (Not Tee-Object: it buffers, and a killed run lost
# every line it had printed, measured 2026-10-16.) The script arrives through process substitution, not a pipe into
# `bash -s`, so a command inside it that reads stdin cannot swallow the rest of the script. Name
# and run are checked against fixed patterns first, so the string wsl.exe receives holds no `$`
# and the launcher expands nothing. A missing script throws here: process substitution of a
# missing file hands bash an empty script, which exits 0 (measured 2026-10-16).
function Invoke-GateWsl([string]$Name) {
    Assert-Run
    if ($Name -cnotmatch '^[A-Za-z0-9-]+$') { throw "Invoke-GateWsl: '$Name' is not a script name" }
    $src = Join-Path $Root "wsl\$Name.sh"
    if (-not (Test-Path -LiteralPath $src -PathType Leaf)) { throw "Invoke-GateWsl: no script saved at $src (nothing ran: save it exactly as written, then run it)" }
    $ledger = Join-Path $G 'log\runs.txt'
    $log = Join-Path $G "log\$Name.txt"
    "STARTED $Name at $(Get-Date -Format o)" | Add-Content -LiteralPath $ledger
    "=== $Name, run $Run, started $(Get-Date -Format o)" | Add-Content -LiteralPath $log
    wsl -d Ubuntu-24.04 -- bash -c "bash <(tr -d '\r' < /mnt/c/gpb010/wsl/$Name.sh) $Run 2>&1" | ForEach-Object { $_; Add-Content -LiteralPath $log -Value $_ }
    $code = $LASTEXITCODE
    "EXIT $Name = $code at $(Get-Date -Format o)" | Add-Content -LiteralPath $ledger
    "EXIT $Name = $code"
}

# After a native command in a pwsh block: prints "<What>: exit <code> (<time>)" and throws on a
# nonzero code, so a block never runs on past a failed git command.
function Assert-Exit([string]$What) {
    $c = $LASTEXITCODE
    "${What}: exit $c ($(Get-Date -Format o))"
    if ($c -ne 0) { throw "BLOCKED: $What exited $c" }
}

# One `filesystem list --json` as rows: the six fields rule 1 compares (uid, name, type,
# creationTime, modificationTime, parentUid), plus path and trashTime. Timestamps stay strings.
function Get-Rows([string]$Path) {
    $raw = & proton-drive filesystem list $Path --json 2>> $errLog
    $code = $LASTEXITCODE
    if ($code -ne 0) { throw "filesystem list $Path exited $code`n$($raw | Out-String)" }
    $items = ($raw | Out-String) | ConvertFrom-Json -DateKind String
    foreach ($i in @($items)) {
        if ($null -eq $i) { continue }
        [pscustomobject]@{
            path = "$Path/$($i.name.value)"; name = [string]$i.name.value; type = [string]$i.type
            uid = [string]$i.uid; parentUid = [string]$i.parentUid
            creationTime = [string]$i.creationTime; modificationTime = [string]$i.modificationTime
            trashTime = [string]$i.trashTime
        }
    }
}

# Every row beneath Path, depth first: rule 3's full subtree enumeration.
function Get-Subtree([string]$Path) {
    foreach ($r in @(Get-Rows $Path)) {
        $r
        if ($r.type -ceq 'folder') { Get-Subtree $r.path }
    }
}

# Saves a listing (with -Recurse, a whole subtree) to <run>\snap\<Label>.json and shows it. A
# label is used once per run. Trash lag: for a while a just-trashed node still appears in `list`,
# carrying a trashTime (docs/research/probes/stage1-results.json, transientTrashVisibilityInList;
# stage5-gate.md:536-538; stage6-gate.md 5.4: still there at 21 s, gone by 112 s). Every push
# trashes its `.lock` as its last act (internal/repo/lock.go:135), so a listing taken right after
# a push can show it. So while a live row (any path outside /trash) carries a trashTime, this
# prints a LAG line naming each such row with its trashTime, waits $lagWait seconds and re-takes
# the listing, at most $lagRetakes times. Only the last listing is saved and judged. A trashTime
# row that survives it stays in the snapshot, and Compare-Snapshot flags it.
function Save-Snapshot([string]$Label, [string]$Path, [switch]$Recurse) {
    Assert-Run
    $file = Join-Path $G "snap\$Label.json"
    if (Test-Path -LiteralPath $file) { throw "Save-Snapshot: $Label already exists in run $Run (a label is used once)" }
    $take = { @(if ($Recurse) { Get-Subtree $Path } else { Get-Rows $Path }) }
    $rows = @(& $take)
    for ($n = 1; $n -le $lagRetakes; $n++) {
        $lag = @($rows | Where-Object { $_.trashTime -and -not $_.path.StartsWith('/trash/') })
        if ($lag.Count -eq 0) { break }
        "LAG: $($lag.Count) live row(s) carry a trashTime ($(@($lag | ForEach-Object { "$($_.path) @ $($_.trashTime)" }) -join ', ')); waiting $lagWait s, re-take $n of $lagRetakes of $Label"
        Start-Sleep -Seconds $lagWait
        $rows = @(& $take)
    }
    ConvertTo-Json -InputObject $rows -Depth 3 | Set-Content -LiteralPath $file
    "SNAPSHOT $Label = $Path$(if ($Recurse) { ' (whole subtree)' }): $($rows.Count) row(s)"
    $rows | Format-Table path, type, uid, modificationTime, trashTime -AutoSize | Out-String -Width 400
}

# Rule 1: compares two snapshots as row sets on the six fields, never as raw JSON. Prints every
# ADDED, REMOVED and CHANGED row (CHANGED: same uid, another field differs), then one verdict
# line. A live row carrying a trashTime is flagged as well (not in /trash, where every row has one):
# Save-Snapshot has already waited and re-taken, so such a row is no longer lag (BLOCKED).
# A missing snapshot is an error, never an empty set.
function Compare-Snapshot([string]$Before, [string]$After) {
    Assert-Run
    foreach ($l in $Before, $After) {
        if (-not (Test-Path -LiteralPath (Join-Path $G "snap\$l.json"))) { throw "Compare-Snapshot: no snapshot named $l" }
    }
    $fields = 'uid', 'name', 'type', 'creationTime', 'modificationTime', 'parentUid'
    $read = { param($l) @(Get-Content -LiteralPath (Join-Path $G "snap\$l.json") -Raw | ConvertFrom-Json -DateKind String | Where-Object { $null -ne $_ }) }
    $a = @(& $read $Before); $b = @(& $read $After)
    $key = { param($r) ($fields | ForEach-Object { [string]$r.$_ }) -join "`t" }
    $inA = [Collections.Generic.HashSet[string]]::new([StringComparer]::Ordinal)
    $inB = [Collections.Generic.HashSet[string]]::new([StringComparer]::Ordinal)
    foreach ($r in $a) { [void]$inA.Add((& $key $r)) }
    foreach ($r in $b) { [void]$inB.Add((& $key $r)) }
    $gone = @($a | Where-Object { -not $inB.Contains((& $key $_)) })
    $new = @($b | Where-Object { -not $inA.Contains((& $key $_)) })
    $lines = @()
    foreach ($n in $new) {
        $o = @($gone | Where-Object { $_.uid -ceq $n.uid })
        if ($o.Count -eq 1) {
            $d = @($fields | Where-Object { [string]$o[0].$_ -cne [string]$n.$_ } | ForEach-Object { "$_ '$($o[0].$_)' -> '$($n.$_)'" })
            $lines += "  CHANGED $($n.path): $($d -join '; ')"
        } else { $lines += "  ADDED   $($n.path) ($($n.type), uid $($n.uid))" }
    }
    foreach ($o in $gone) {
        if (@($new | Where-Object { $_.uid -ceq $o.uid }).Count -eq 0) { $lines += "  REMOVED $($o.path) ($($o.type), uid $($o.uid))" }
    }
    foreach ($r in $b) { if ($r.trashTime -and -not $r.path.StartsWith('/trash/')) { $lines += "  LIVE ROW WITH trashTime: $($r.path) ($($r.trashTime))" } }
    if ($lines.Count -eq 0) { "COMPARE $Before -> ${After}: NO DIFFERENCE ($($a.Count) row(s))" }
    else { "COMPARE $Before -> ${After}: $($lines.Count) difference(s)"; $lines }
}

# Spec section 7's read-only Windows check: `filesystem info /my-files` with the Windows CLI.
# PASS means exit 0, a folder, and the uid of this run's baseline. -Baseline records that
# baseline, once per run: a second -Baseline throws, so no later check is ever compared with a
# baseline it just wrote (the baseline call's own PASS means exit 0 and a folder). Every result is
# appended to <run>\log\wincheck-ledger.txt, which Test-UnpauseCondition reads.
function Invoke-WindowsCheck([string]$Label, [switch]$Baseline) {
    Assert-Run
    $file = Join-Path $G 'log\wincheck-baseline-uid.txt'
    if ($Baseline -and (Test-Path -LiteralPath $file)) { throw "Invoke-WindowsCheck: run $Run already has a baseline; -Baseline is used once per run" }
    $ef = Join-Path $G "log\wincheck-$Label.stderr.txt"
    $raw = & proton-drive filesystem info /my-files --json 2> $ef
    $code = $LASTEXITCODE
    $text = $raw | Out-String
    $text | Set-Content -LiteralPath (Join-Path $G "log\wincheck-$Label.txt")
    $uid = ''
    try { $j = $text | ConvertFrom-Json -DateKind String; if ([string]$j.type -ceq 'folder') { $uid = [string]$j.uid } } catch { }
    if ($Baseline -and $code -eq 0 -and $uid) { Set-Content -LiteralPath $file -Value $uid }
    $want = if (Test-Path -LiteralPath $file) { (Get-Content -LiteralPath $file -Raw).Trim() } else { '' }
    $pass = ($code -eq 0) -and [bool]$uid -and ($uid -ceq $want)
    $verdict = if ($pass) { 'PASS' } else { 'FAIL' }
    "$Label $verdict $(Get-Date -Format o)" | Add-Content -LiteralPath (Join-Path $G 'log\wincheck-ledger.txt')
    "WINDOWS CHECK ${Label}: exit=$code uid=$uid baseline=$want -> $verdict"
    if (-not $pass) { $text; Get-Content -LiteralPath $ef -Raw }
}

# Gate step 0: the probe-to-gate boundary. Each probe run's baseline uid under C:\gpb010 must
# equal this gate run's. None found (the probe ran elsewhere, or C:\gpb010 was rebuilt) is
# recorded, not a BLOCK: the boundary is then not compared.
function Compare-ProbeBaseline {
    Assert-Run
    $mine = Join-Path $G 'log\wincheck-baseline-uid.txt'
    if (-not (Test-Path -LiteralPath $mine)) { throw 'Compare-ProbeBaseline: this run has no baseline yet' }
    $want = (Get-Content -LiteralPath $mine -Raw).Trim()
    $found = @(Get-ChildItem -LiteralPath $Root -Directory | Where-Object { $_.Name -cmatch '^probe-a[1-9][0-9]*$' } |
        ForEach-Object { Join-Path $_.FullName 'log\wincheck-baseline-uid.txt' } | Where-Object { Test-Path -LiteralPath $_ })
    if ($found.Count -eq 0) { "PROBE BASELINE: none under $Root (recorded, not a BLOCK; the probe-to-gate boundary is not compared)"; return }
    $same = $true
    foreach ($f in $found) { $u = (Get-Content -LiteralPath $f -Raw).Trim(); "probe baseline ${f}: $u"; if ($u -cne $want) { $same = $false } }

# Step 4's ref-set comparison, as row sets. A ref-set file in <run>\refsets holds `<sha> <ref>`
# lines: `git ls-remote` output, or a clone's
# `git for-each-ref --format='%(objectname) %(refname)' refs/remotes/proton-v2`. A clone's
# refs/remotes/proton-v2/<b> is compared as refs/heads/<b>. When either side is a clone, HEAD is
# left out of both sides (fetch does not move a clone's proton-v2/HEAD).
function Read-RefSet([string]$Label) {
    $f = Join-Path $G "refsets\$Label.txt"
    if (-not (Test-Path -LiteralPath $f)) { throw "Compare-RefSet: no ref set named $Label" }
    $clone = $false
    $rows = foreach ($l in @(Get-Content -LiteralPath $f)) {
        if (-not $l.Trim()) { continue }
        $p = -split $l
        if ($p.Count -ne 2 -or $p[0] -cnotmatch '^[0-9a-f]{40}$') { throw "Compare-RefSet: $Label holds a line that is not '<sha> <ref>': [$l]" }
        $ref = $p[1]
        if ($ref.StartsWith('refs/remotes/proton-v2/')) {
            $clone = $true
            $rest = $ref.Substring(23)
            $ref = if ($rest -ceq 'HEAD') { 'HEAD' } else { "refs/heads/$rest" }
        }
        "$($p[0]) $ref"
    }
    [pscustomobject]@{ Clone = $clone; Rows = @($rows) }
}
function Compare-RefSet([string]$A, [string]$B) {
    Assert-Run
    $x = Read-RefSet $A; $y = Read-RefSet $B
    $drop = $x.Clone -or $y.Clone
    $sa = [Collections.Generic.HashSet[string]]::new([StringComparer]::Ordinal)
    $sb = [Collections.Generic.HashSet[string]]::new([StringComparer]::Ordinal)
    foreach ($r in $x.Rows) { if (-not ($drop -and $r.EndsWith(' HEAD'))) { [void]$sa.Add($r) } }
    foreach ($r in $y.Rows) { if (-not ($drop -and $r.EndsWith(' HEAD'))) { [void]$sb.Add($r) } }
    $onlyA = @($sa | Where-Object { -not $sb.Contains($_) } | Sort-Object)
    $onlyB = @($sb | Where-Object { -not $sa.Contains($_) } | Sort-Object)
    $note = if ($drop) { ', HEAD left out' } else { '' }
    if ($onlyA.Count -eq 0 -and $onlyB.Count -eq 0) { "REFSET $A == ${B}: EQUAL ($($sa.Count) ref(s)$note)" }
    else { "REFSET $A vs ${B}: DIFFER$note"; $onlyA | ForEach-Object { "  ONLY IN ${A}: $_" }; $onlyB | ForEach-Object { "  ONLY IN ${B}: $_" } }
}

        }

    if ($problems.Count) { throw 'BLOCKED: the ownership record does not match the account' }
}
```

### Step 4: the cross-platform round trip

Repo **L** (`$XL`, `v010-linux-xl-<SUF>`) is pushed from Linux and cloned on Windows. Repo **W**
(`$XW`, `v010-linux-xw-<SUF>`) is pushed from Windows and cloned in WSL. Then each origin pushes an
update and a branch deletion in one push, and the other platform's clone fetches them (§7). Last,
each clone pushes a commit back, so each platform's helper also writes into a remote the other
platform's helper made, and each origin fetches it.

*Brief author's call: the push-back (4.9–4.11).* §7 asks for a push from each origin and a fetch
into each clone. Without the push-back, no step has a helper write into a remote the other
platform created, which is the half of "a repo stays usable from every machine" that a clone and a
fetch cannot show. It adds two pushes, and so two `.lock` files to the tally.

*Brief author's call:* the clones fetch with `--prune`, so the deletion is visible in their refs.

**The ref-set comparison, scripted.** Every `git ls-remote`, and every clone's
`git for-each-ref --format='%(objectname) %(refname)' refs/remotes/proton-v2`, is saved to
`C:\gpb010\<run>\refsets\<label>.txt` (`$W/refsets` in WSL), and `Compare-RefSet` compares two of
them as row sets. A clone's `refs/remotes/proton-v2/<b>` is compared as `refs/heads/<b>`, and
when either side is a clone, HEAD is left out of both. Two platforms' `ls-remote` outputs are
compared whole, HEAD included. *Brief author's call.*

**HEAD in `ls-remote`.** The helper's `list` advertises HEAD as a symref, `@refs/heads/<b> HEAD`,
and only when `<b>` is itself advertised [code `cmd/git-remote-proton/main.go:419-442`]. git
resolves it, so `ls-remote` prints `<sha>	HEAD` with that branch's SHA.

**Which helper Windows git runs.** *Brief author's call:* every Windows block below that runs git
against a remote starts with `Test-WindowsHelper -Require`. It sets the block's PATH to the fresh
registry PATH that step 0 checked, prints every `git-remote-proton` it finds with its hash and
`--version`, checks git's exec-path, and throws (BLOCKED, before any git command) unless the draft
exe is the one and only helper git can find. The PATH of the runner's own shell therefore cannot
differ from the PATH step 0 checked. [Measured 2026-10-16: `git`, `proton-drive`, `gh` and `go`
all resolve on that fresh PATH.]

Every git command in a Windows block is followed by `Assert-Exit`, which prints its exit code and

### Step 5: case variants, all inside the gate root (D2(a): the refusal branch)

All work is on `$CASE` (`v010-linux-case-<SUF>`). D2(a) is ruled, so §7's "If D2 allows them"
branch does not apply.

**How a refusal is checked.** After every push, a Windows snapshot of the whole repo subtree is
compared with the snapshot before it (rule 1).

**What a comparison can and cannot show.** `NO DIFFERENCE` shows that the subtree ends as it
began: no pack, no ref and no folder was left behind.

- **For a pack it shows more: none was uploaded.** The helper never trashes a pack. Its only trash
  calls are the lock release, a ref delete, and two kinds of empty-folder cleanup [code
  `internal/repo/lock.go:135`, `internal/repo/push.go:525, 809, 1068`]. That is why 5.1 pushes a
  commit the remote lacks (below).

  trashed".** That none was written rests on where the refusal happens: phase 2, which validates
  the whole batch before anything moves [code `internal/repo/push.go:36-46`], and on the trash
  comparison where the trash can be listed. *Brief author's call:* the claim is stated at that
  strength.

**Trash lag applies to every snapshot in this step.**

- **Why it arises.** Every push, refused or not, trashes its `.lock` as its last act
  [code `internal/repo/lock.go:135`]. For a while after that, the `.lock` can still appear in a
  listing, carrying a `trashTime` (`docs/research/probes/stage1-results.json`,
  "transientTrashVisibilityInList"; `stage5-gate.md:536-538`). The longest lag on record was
  still showing at 21 s and gone by 112 s (`stage6-gate.md` 5.4).
- **What `Save-Snapshot` does about it.** While any live row carries a `trashTime`, it prints a
  `LAG:` line naming each such row and its `trashTime`, waits 60 s, and re-takes the snapshot, at
  most twice. Only the last listing is saved and compared.
- **How to judge it.** In this step a `LAG:` line may name only
  `/my-files/GitRemotes/v010-linux-case-<SUF>/.lock`. That row is lag, not a write, and never a
  BLOCK by itself. A `LAG:` line naming any other path is BLOCKED: in step 5 only the lock is ever
  trashed. A row with a `trashTime` that survives both re-takes is flagged by `Compare-Snapshot`
  (`LIVE ROW WITH trashTime`) and is BLOCKED. *Brief author's call:* 60 s and two re-takes, which
  reaches past the 112 s on record.

Every "exactly" and "NO DIFFERENCE" below is judged on the last listing.

If the refusal had a bug, the push would therefore have to upload a pack, and the snapshot would
