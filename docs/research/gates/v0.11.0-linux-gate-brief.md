`bash` (the WSL distro). The kit uses `ConvertFrom-Json -DateKind`, which "PowerShell 7.5 added"
[doc: Microsoft's `ConvertFrom-Json` reference], so it refuses to load on an older PowerShell. This
machine runs 7.6.7, `C:\Program Files\PowerShell\7\pwsh.exe`, first on PATH [measured 2026-10-16].

- **A `bash` block that starts with a script name** (`# script: <name>`) is a script. The runner
  saves it exactly as written to `C:\gpb011\wsl\<name>.sh` (probe prep says when) and runs it from
  pwsh with `. C:\gpb011\kit.ps1; Invoke-GateWsl <name>`. The launcher hands the script the current
  run's name as `$1`. Never inline a script as `wsl -- bash -c "<commands>"`: WSL's launcher
  expands `$vars` before bash ever sees them.

```powershell

# Dot-source it at the start of every PowerShell call:  . C:\gpb011\kit.ps1
# Its only account calls are `filesystem list` and `filesystem info`, both read-only.
# Every node-name comparison is case-sensitive (-ceq, -clike, -cin, ordinal sets): Main and main
# differ. (Test-GpbEnv matches environment variable names, which Windows folds, without case.)
# Needs PowerShell 7.5 or newer: ConvertFrom-Json -DateKind arrived in 7.5.
$psv = $PSVersionTable.PSVersion
if ([version]"$($psv.Major).$($psv.Minor)" -lt [version]'7.5') { throw "kit: needs PowerShell 7.5 or newer (ConvertFrom-Json -DateKind); this is $psv" }
[Console]::OutputEncoding = [Text.UTF8Encoding]::new()
$Root = 'C:\gpb011'
$lagWait = 60      # seconds Save-Snapshot waits before each re-take of a listing that shows trash lag
$lagRetakes = 2    # at most two re-takes: stage6-gate.md 5.4 saw a folder's lag at 21 s and none by 112 s

# The current run, named by C:\gpb011\run.txt (probe-a1, gate-a1, ...; Start-GateRun writes it).
# $G is the run's folder, $Suf its attempt (a1, a2, ...), which every remote root name carries.

# This run's remote names (a gate run's; a probe run writes nothing remote).
$GR = '/my-files/GitRemotes'
$RootNames = @(foreach ($role in 'contract', 'smoke', 'xl', 'xw', 'case', 'nfd') { "v011-linux-$role-$Suf" })

function Assert-Run {
    if (-not $G -or -not (Test-Path -LiteralPath $G)) { throw 'BLOCKED: no current run (C:\gpb011\run.txt names none, or its folder is missing)' }
}

# Starts a run: creates C:\gpb011\<kind>-a<attempt> with log\, snap\ and refsets\, writes the
# run's random token (token.txt), and names the run in run.txt. A run folder that already exists
# is a stale attempt: BLOCKED, and nothing is written. The WSL prep script copies the token into
# the run's env.sh, and every WSL cleanup script acts only when env.sh carries this token, so a WSL
# folder left by an earlier run of the same name is never cleaned up as this run's.
# Dot-source the kit again before the next command, so $G and the names follow the new run.
function Start-GateRun([string]$Kind, [int]$Attempt) {
    if ($Kind -cnotin 'probe', 'gate' -or $Attempt -lt 1) { throw 'Start-GateRun: the kind is probe or gate, and the attempt is 1 or more' }
    $name = "$Kind-a$Attempt"
    $dir = Join-Path $Root $name
    if (Test-Path -LiteralPath $dir) { throw "BLOCKED: $dir already exists (that run already started; a re-run takes the next attempt number, on Craig's word)" }
    New-Item -ItemType Directory -Path $dir, (Join-Path $dir 'log'), (Join-Path $dir 'snap'), (Join-Path $dir 'refsets') -ErrorAction Stop | Out-Null
    Set-Content -LiteralPath (Join-Path $dir 'token.txt') -Value ([guid]::NewGuid().ToString('N')) -NoNewline
    Set-Content -LiteralPath (Join-Path $Root 'run.txt') -Value $name -NoNewline
    "RUN STARTED: $name ($dir) at $(Get-Date -Format o). Dot-source the kit again before the next command."
}

# Runs C:\gpb011\wsl\<Name>.sh in the distro with the run name as $1, through process
# substitution (so stdin cannot swallow the script). Output (stderr merged) is shown and appended
# to <run>\log\<Name>.txt line by line (Tee-Object buffered and lost a killed run's lines), with
# STARTED/EXIT lines in <run>\log\runs.txt. Name and run match fixed patterns, so wsl.exe gets no
# `$` to expand. A missing script throws here: bash would run it as empty and exit 0 (measured).
function Invoke-GateWsl([string]$Name) {
    Assert-Run
    if ($Name -cnotmatch '^[A-Za-z0-9-]+$') { throw "Invoke-GateWsl: '$Name' is not a script name" }
    $src = Join-Path $Root "wsl\$Name.sh"
    if (-not (Test-Path -LiteralPath $src -PathType Leaf)) { throw "Invoke-GateWsl: no script saved at $src (nothing ran: save it exactly as written, then run it)" }
    $ledger = Join-Path $G 'log\runs.txt'
    $log = Join-Path $G "log\$Name.txt"
    "STARTED $Name at $(Get-Date -Format o)" | Add-Content -LiteralPath $ledger
    "=== $Name, run $Run, started $(Get-Date -Format o)" | Add-Content -LiteralPath $log
    wsl -d Ubuntu-24.04 -- bash -c "bash <(tr -d '\r' < /mnt/c/gpb011/wsl/$Name.sh) $Run 2>&1" | ForEach-Object { $_; Add-Content -LiteralPath $log -Value $_ }

# After a native command in a pwsh block: prints "<What>: exit <code> (<time>)" and throws on a
# nonzero code, so a block never runs on past a failed git command.
function Assert-Exit([string]$What) {
    $c = $LASTEXITCODE
    "${What}: exit $c ($(Get-Date -Format o))"
    if ($c -ne 0) { throw "BLOCKED: $What exited $c" }
}

# One `filesystem list --json` as rows: the six fields rule 1 compares (uid, name, type,
# creationTime, modificationTime, parentUid), plus path and trashTime. Timestamps stay strings.
# A row without a uid, name or modificationTime throws: the comparisons would silently weaken.
function Get-Rows([string]$Path) {
    $raw = & proton-drive filesystem list $Path --json 2>> $errLog
    $code = $LASTEXITCODE
    if ($code -ne 0) { throw "filesystem list $Path exited $code`n$($raw | Out-String)" }
    $items = ($raw | Out-String) | ConvertFrom-Json -DateKind String
    foreach ($i in @($items)) {
        if ($null -eq $i) { continue }
        if (-not $i.uid -or -not $i.name.value -or -not $i.modificationTime) { throw "filesystem list ${Path}: a row lacks uid, name or modificationTime: $($i | ConvertTo-Json -Compress -Depth 3)" }
        [pscustomobject]@{
            path = "$Path/$($i.name.value)"; name = [string]$i.name.value; type = [string]$i.type
            uid = [string]$i.uid; parentUid = [string]$i.parentUid
            creationTime = [string]$i.creationTime; modificationTime = [string]$i.modificationTime
            trashTime = [string]$i.trashTime
        }
    }
}

# Every row beneath Path, depth first: rule 3's full subtree enumeration.
function Get-Subtree([string]$Path) {
    foreach ($r in @(Get-Rows $Path)) {
        $r
        if ($r.type -ceq 'folder') { Get-Subtree $r.path }
    }
}

# Saves a listing (with -Recurse, a whole subtree) to <run>\snap\<Label>.json, once per label.
# Trash lag: a just-trashed node can stay listed with a trashTime (stage6-gate.md 2.5, 5.2, 5.4),
# and every push trashes its .lock last (internal/repo/lock.go:135). So while a live row (outside
# /trash) carries a trashTime, this prints a LAG line, waits $lagWait s and re-takes, at most
# $lagRetakes times; only the last listing is saved. The file is written as .partial, then renamed,
# so a killed snapshot leaves no <Label>.json, never a half set.
function Save-Snapshot([string]$Label, [string]$Path, [switch]$Recurse) {
    Assert-Run
    $file = Join-Path $G "snap\$Label.json"
    if (Test-Path -LiteralPath $file) { throw "Save-Snapshot: $Label already exists in run $Run (a label is used once)" }
    $take = { @(if ($Recurse) { Get-Subtree $Path } else { Get-Rows $Path }) }
    $rows = @(& $take)
    for ($n = 1; $n -le $lagRetakes; $n++) {
        $lag = @($rows | Where-Object { $_.trashTime -and -not $_.path.StartsWith('/trash/') })
        if ($lag.Count -eq 0) { break }
        "LAG: $($lag.Count) live row(s) carry a trashTime ($(@($lag | ForEach-Object { "$($_.path) @ $($_.trashTime)" }) -join ', ')); waiting $lagWait s, re-take $n of $lagRetakes of $Label"
        Start-Sleep -Seconds $lagWait
        $rows = @(& $take)
    }
    ConvertTo-Json -InputObject $rows -Depth 3 | Set-Content -LiteralPath "$file.partial"
    Move-Item -LiteralPath "$file.partial" -Destination $file
    "SNAPSHOT $Label = $Path$(if ($Recurse) { ' (whole subtree)' }): $($rows.Count) row(s)"
    $rows | Format-Table path, type, uid, modificationTime, trashTime -AutoSize | Out-String -Width 400
}

# Rule 1: compares two snapshots as row sets on the six fields, never as raw JSON. Prints every
# ADDED, REMOVED and CHANGED row (CHANGED: same uid, another field differs), then one verdict
# line. A row the later snapshot still lists with a trashTime (outside /trash, where every row has
# one) is not counted as a difference: it is listed once as TRASHED, STILL LISTED, for the brief's
# trashed-row rule; such a row in the earlier snapshot is left out, so its later absence is no
# REMOVED. A label X with a re-take X-r is read as X-r, so a re-take carries forward.
# A missing snapshot is an error, never an empty set.
function Compare-Snapshot([string]$Before, [string]$After) {
    Assert-Run
    $file = { param($l) $r = Join-Path $G "snap\$l-r.json"; if (Test-Path -LiteralPath $r) { $r } else { Join-Path $G "snap\$l.json" } }
    foreach ($l in $Before, $After) {
        if (-not (Test-Path -LiteralPath (& $file $l))) { throw "Compare-Snapshot: no snapshot named $l" }
        if ((& $file $l).EndsWith('-r.json')) { "  USING RE-TAKE: $l-r for $l" }
    }
    $fields = 'uid', 'name', 'type', 'creationTime', 'modificationTime', 'parentUid'
    $read = { param($l) @(Get-Content -LiteralPath (& $file $l) -Raw | ConvertFrom-Json -DateKind String | Where-Object { $null -ne $_ }) }
    $a = @(& $read $Before | Where-Object { -not ($_.trashTime -and -not $_.path.StartsWith('/trash/')) }); $b = @(& $read $After)
    $key = { param($r) ($fields | ForEach-Object { [string]$r.$_ }) -join "`t" }
    $inA = [Collections.Generic.HashSet[string]]::new([StringComparer]::Ordinal)
    $inB = [Collections.Generic.HashSet[string]]::new([StringComparer]::Ordinal)
    foreach ($r in $a) { [void]$inA.Add((& $key $r)) }
    foreach ($r in $b) { [void]$inB.Add((& $key $r)) }
    $gone = @($a | Where-Object { -not $inB.Contains((& $key $_)) })
    $new = @($b | Where-Object { -not $inA.Contains((& $key $_)) })
    $lines = @()
    foreach ($n in $new) {
        if ($n.trashTime -and -not $n.path.StartsWith('/trash/')) { continue }
        $o = @($gone | Where-Object { $_.uid -ceq $n.uid })
        if ($o.Count -eq 1) {
            $d = @($fields | Where-Object { [string]$o[0].$_ -cne [string]$n.$_ } | ForEach-Object { "$_ '$($o[0].$_)' -> '$($n.$_)'" })
            $lines += "  CHANGED $($n.path): $($d -join '; ')"
        } else { $lines += "  ADDED   $($n.path) ($($n.type), uid $($n.uid))" }
    }
    foreach ($o in $gone) {
        if (@($new | Where-Object { $_.uid -ceq $o.uid }).Count -eq 0) { $lines += "  REMOVED $($o.path) ($($o.type), uid $($o.uid))" }
    }
    $held = @($b | Where-Object { $_.trashTime -and -not $_.path.StartsWith('/trash/') } | ForEach-Object { "  TRASHED, STILL LISTED: $($_.path) ($($_.trashTime))" })
    $note = if ($held.Count) { "; $($held.Count) trashed row(s) still listed" } else { '' }
    if ($lines.Count -eq 0) { "COMPARE $Before -> ${After}: NO DIFFERENCE ($($a.Count) row(s))$note"; $held }
    else { "COMPARE $Before -> ${After}: $($lines.Count) difference(s)$note"; $lines; $held }
}

# Spec section 7's read-only Windows check: `filesystem info /my-files` with the Windows CLI.
# PASS means exit 0, a folder, and the uid of this run's baseline. -Baseline records that
# baseline, once per run: a second -Baseline throws, so no later check is ever compared with a
# baseline it just wrote (the baseline call's own PASS means exit 0 and a folder). A run with no
# baseline yet (it stopped before taking one) gets NO-BASELINE for exit 0 and a folder, never a
# false FAIL. Every result is appended to <run>\log\wincheck-ledger.txt, which
# Test-UnpauseCondition reads.
function Invoke-WindowsCheck([string]$Label, [switch]$Baseline) {
    Assert-Run
    $file = Join-Path $G 'log\wincheck-baseline-uid.txt'
    if ($Baseline -and (Test-Path -LiteralPath $file)) { throw "Invoke-WindowsCheck: run $Run already has a baseline; -Baseline is used once per run" }
    $ef = Join-Path $G "log\wincheck-$Label.stderr.txt"
    $raw = & proton-drive filesystem info /my-files --json 2> $ef
    $code = $LASTEXITCODE
    $text = $raw | Out-String
    $text | Set-Content -LiteralPath (Join-Path $G "log\wincheck-$Label.txt")
    $uid = ''
    try { $j = $text | ConvertFrom-Json -DateKind String; if ([string]$j.type -ceq 'folder') { $uid = [string]$j.uid } } catch { }
    if ($Baseline -and $code -eq 0 -and $uid) { Set-Content -LiteralPath $file -Value $uid }
    $want = if (Test-Path -LiteralPath $file) { (Get-Content -LiteralPath $file -Raw).Trim() } else { '' }
    $pass = ($code -eq 0) -and [bool]$uid -and ($uid -ceq $want)
    $verdict = if ($pass) { 'PASS' } elseif (-not $want -and $code -eq 0 -and $uid) { 'NO-BASELINE' } else { 'FAIL' }
    "$Label $verdict $(Get-Date -Format o)" | Add-Content -LiteralPath (Join-Path $G 'log\wincheck-ledger.txt')
    "WINDOWS CHECK ${Label}: exit=$code uid=$uid baseline=$want -> $verdict"
    if (-not $pass) { $text; Get-Content -LiteralPath $ef -Raw }
}

# Spec section 7's condition for unpausing, read from this run's ledger: every Windows check the
# run made passed, and its final check ($Final: probe-6 or gate-6) ran and passed. A FAIL earlier
# in the run (for example gate-2) still blocks the unpause after a later PASS. A run that stopped
# before taking its baseline has only NO-BASELINE lines. Its final check reading the account root
# is then enough, but only if runs.txt shows no WSL script started other than prep, the 6.0
# barrier and the cleanup scripts (with no baseline, each skips or stays local), and it says so.
function Test-UnpauseCondition([string]$Final) {
    Assert-Run

# Spec section 7 step 0: the helper git resolves on Windows must be the draft exe's bytes. git
# searches its own exec-path (`git --exec-path`) before PATH, and Get-Command cannot see a copy
# there, so any git-remote-proton* in it is a NO. PATH is the one a fresh shell builds (Machine,
# then User; .NET returns %VAR% entries already expanded, measured 2026-10-16), with empty entries
# dropped. It SETS this process's PATH to that fresh PATH, so every git command after it in the same
# block resolves git-remote-proton exactly as checked. With -Require it throws unless the draft is
# the one and only hit, which stops the block before any git command runs.
function Test-WindowsHelper([switch]$Require) {
    Assert-Run

}

# Step 4's ref-set comparison, as row sets. A ref-set file in <run>\refsets holds `<sha> <ref>`
# lines: `git ls-remote` output, or a clone's
# `git for-each-ref --format='%(objectname) %(refname)' refs/remotes/proton-v2`. A clone's
# refs/remotes/proton-v2/<b> is compared as refs/heads/<b>. When either side is a clone, HEAD is
# left out of both sides (fetch does not move a clone's proton-v2/HEAD).
function Read-RefSet([string]$Label) {
    $f = Join-Path $G "refsets\$Label.txt"
    if (-not (Test-Path -LiteralPath $f)) { throw "Compare-RefSet: no ref set named $Label" }
    $clone = $false
    $rows = foreach ($l in @(Get-Content -LiteralPath $f)) {
        if (-not $l.Trim()) { continue }
        $p = -split $l
        if ($p.Count -ne 2 -or $p[0] -cnotmatch '^[0-9a-f]{40}$') { throw "Compare-RefSet: $Label holds a line that is not '<sha> <ref>': [$l]" }
        $ref = $p[1]
        if ($ref.StartsWith('refs/remotes/proton-v2/')) {
            $clone = $true
            $rest = $ref.Substring(23)
            $ref = if ($rest -ceq 'HEAD') { 'HEAD' } else { "refs/heads/$rest" }
        }
        "$($p[0]) $ref"
    }
    [pscustomobject]@{ Clone = $clone; Rows = @($rows) }
}
function Compare-RefSet([string]$A, [string]$B) {
    Assert-Run
    $x = Read-RefSet $A; $y = Read-RefSet $B
    $drop = $x.Clone -or $y.Clone
    $sa = [Collections.Generic.HashSet[string]]::new([StringComparer]::Ordinal)
    $sb = [Collections.Generic.HashSet[string]]::new([StringComparer]::Ordinal)
    foreach ($r in $x.Rows) { if (-not ($drop -and $r.EndsWith(' HEAD'))) { [void]$sa.Add($r) } }
    foreach ($r in $y.Rows) { if (-not ($drop -and $r.EndsWith(' HEAD'))) { [void]$sb.Add($r) } }
    $onlyA = @($sa | Where-Object { -not $sb.Contains($_) } | Sort-Object)
    $onlyB = @($sb | Where-Object { -not $sa.Contains($_) } | Sort-Object)
    $note = if ($drop) { ', HEAD left out' } else { '' }
    if ($onlyA.Count -eq 0 -and $onlyB.Count -eq 0) { "REFSET $A == ${B}: EQUAL ($($sa.Count) ref(s)$note)" }
    else { "REFSET $A vs ${B}: DIFFER$note"; $onlyA | ForEach-Object { "  ONLY IN ${A}: $_" }; $onlyB | ForEach-Object { "  ONLY IN ${B}: $_" } }
}

function ConvertTo-Esc([string]$s) {
    $b = [Text.StringBuilder]::new()
    foreach ($r in $s.EnumerateRunes()) {
        $v = $r.Value
        if ($v -eq 92) { [void]$b.Append('<BS>') }
        elseif ($v -eq 9 -or ($v -ge 32 -and $v -le 126)) { [void]$b.Append([char]$v) }
        else { [void]$b.Append(('<U+{0:X4}>' -f $v)) }
    }
    $b.ToString()
}
```

### Step 5: case and composition variants, all inside the gate root (D2(a), O5(d): the refusal branch)

Steps 5.0 to 5.4 work on `$CASE` (`v011-linux-case-<SUF>`). D2(a) is ruled, so §7's "If D2 allows
them" branch does not apply. Steps 5.5 and 5.6, the composition refusal O5(d) adds, work on a root
of their own, `$NFDL` (`v011-linux-nfd-<SUF>`), so that they depend on none of 5.0 to 5.4's frames
or tallies, and so that the pair 5.4 lays down on the case root cannot put string 10's warning
into them (*the steps file's call*, kept).

**How a refusal is checked.** After every push, a Windows snapshot of the whole repo subtree is
compared with the snapshot before it (rule 1).

**What a comparison can and cannot show.** `NO DIFFERENCE` shows that the subtree ends as it
began: no pack, no ref and no folder was left behind.

- **For a pack it shows more: none was uploaded.** The helper never trashes a pack. Its only trash
  calls are the lock release, a ref delete, and two kinds of empty-folder cleanup [code
  `internal/repo/lock.go:135`, `internal/repo/push.go:616, 932, 1191`]. That is why 5.1 pushes a
  commit the remote lacks (below).
- **For a ref or a folder, the listing alone cannot tell "never written" from "written, then
  trashed".** That none was written rests on where the refusal happens: phase 2, which validates
  the whole batch before anything moves [code `internal/repo/push.go:35-46`], and on the trash
  comparison where the trash can be listed. *Brief author's call:* the claim is stated at that
  strength.
- **A second view, for freshness.** Every snapshot comes from the Windows CLI, a different session
  from the WSL CLI that made the push. A stale Windows view would make a negative comparison pass
  falsely: `NO DIFFERENCE` because the listing did not move. So each refused push (5.1, 5.3's
  `Feat/x`, 5.4's `MAIN`, 5.6's NFD create) also lists `refs/heads`, and at 5.1 and 5.6 `packs`,
  from the WSL session that pushed, whose cache is the gate's own, and the two views must agree.
  A script that exits 99 could not take that WSL listing: BLOCKED, whatever the push did.
  *Brief author's call.*

**Trash lag applies to every snapshot in this step.**

- **Why it arises.** Every push, refused or not, trashes its `.lock` as its last act
  [code `internal/repo/lock.go:135`]. For a while after that, the `.lock` can still appear in a
  listing, carrying a `trashTime` (`docs/research/probes/stage1-results.json`,
  "transientTrashVisibilityInList"; `stage5-gate.md:536-538`). The longest lag on record was
  still showing at 21 s and gone by 112 s (`stage6-gate.md` 5.4).
- **What `Save-Snapshot` does about it.** While any live row carries a `trashTime`, it prints a
  `LAG:` line naming each such row and its `trashTime`, waits 60 s, and re-takes the snapshot, at
  most twice. Only the last listing is saved and compared.
- **How to judge it.** In this step a `LAG:` line may name only
  `/my-files/GitRemotes/v011-linux-case-<SUF>/.lock`, or, in 5.5 and 5.6,
  `/my-files/GitRemotes/v011-linux-nfd-<SUF>/.lock`. That row is lag, not a write, and never a
  BLOCK by itself. (v0.10.0's step 5 printed no `LAG:` line at all [record
  `v0.10.0-linux-gate.md:518`].) A `LAG:` line naming any other path is BLOCKED: in step 5 only the lock is ever
  trashed. A row with a `trashTime` that survives both re-takes is printed by `Compare-Snapshot`
  as `TRASHED, STILL LISTED`, is not counted as a difference, and is handled as "A trashed row that
  outlives the re-takes" says: recorded, and Craig decides on a re-take. *Brief author's call:* 60 s
  and two re-takes, which reaches past the 112 s on record.

Every "exactly" and "NO DIFFERENCE" below is judged on the last listing.

*Brief author's call: a withheld object.* 5.1 pushes a commit the remote does not yet hold (C2).
If the refusal had a bug, the push would therefore have to upload a pack, and the snapshot would
show it. This is the stage6 brief's discriminating-power lesson: a commit the remote already has
needs no pack, so the snapshot could not tell a refusal from a bug.
